# CPU and GPU overclock patch archive

This folder archives the GPU 1100 MHz and CPU OC1/OC2/OC3 patch scripts.

These are distinct experimental profiles with different tables/voltage assumptions. The presence of a script here does not mean that its profile is enabled in the current branch or release. Device-specific boot, stability, thermal, and sustained-load testing must be tracked separately.

The active scripts remain under `scripts/`; keep these archive snapshots synchronized after modifications.
